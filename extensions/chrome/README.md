# Grain for Chrome

Right-click any image on the web and choose **Who made this image? (Grain)**. Grain fetches the image and checks it against the registry on Monad: who registered it, whether its watermark is genuine, and whether a forged credential has been stamped onto it.

The extension's only permission is the right-click menu. It can't read pages, see your browsing or change any site. It works in Chrome, Edge, Brave and Arc.

## Install

Not yet on the Chrome Web Store, so install it directly:

1. Download [grain-extension.zip](https://grain-on-monad.vercel.app/grain-extension.zip) and unzip it.
2. Open `chrome://extensions` and switch on **Developer mode** (top right).
3. Click **Load unpacked** and choose the unzipped folder.

Or from this repository: load `extensions/chrome` the same way.
